Amper

Chemistry autocorrect for Google Docs

Before you enable Amper

Amper reads the text you type in Google Docs solely to detect and format chemistry notation. Processing happens locally in your browser. Document text is not sent to Amper servers or third parties.

Choose Enable Amper to consent to this processing. You can turn Amper off later in this popup.
